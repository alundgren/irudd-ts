Check configured file roles

Report analyzed files that do not match the configured roles.

archguard.json

{
  "schemaVersion": 1,
  "include": ["src/**/*.ts"],
  "repository": {
    "roles": [
      {
        "id": "service",
        "files": ["src/services/**"]
      },
      {
        "id": "contract",
        "files": ["src/contracts/**"]
      },
      {
        "id": "test",
        "files": ["src/*.test.ts"]
      }
    ],
    "rules": [
      {
        "id": "classify-source",
        "kind": "classified",
        "files": ["src/**"]
      }
    ]
  }
}

src/misc.ts

export {};

Archguard reports

src/misc.ts:1:1: classify-source: expected exactly one repository role, found 0

Fix · src/contracts/message.ts

export {};

Fix

rm src/misc.ts

Exit 1 with the finding above. After the fix, exit 0.
