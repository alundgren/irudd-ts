Report specified calls in dependencies

Report a dependency path to a module containing an Effect.runPromise call.

archguard.json

{
  "schemaVersion": 1,
  "include": ["src/**/*.ts"],
  "rules": [
    {
      "id": "domain-no-run",
      "kind": "forbiddenCall",
      "files": ["src/domain/**"],
      "origins": ["effect/Effect#runPromise"],
      "transitive": true
    }
  ]
}

src/domain/orders.ts

import '../runner';

src/runner.ts

import * as E from 'effect/Effect';
E.runPromise(task);

Archguard reports

src/domain/orders.ts:1:1: domain-no-run: reachable dependency src/runner.ts calls effect/Effect#runPromise
  src/domain/orders.ts -> src/runner.ts -> src/runner.ts:36

Fix · src/domain/orders.ts

export const order = 1;

Exit 1 with the finding above. After the fix, exit 0.
