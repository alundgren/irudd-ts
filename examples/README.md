# Examples

Run commands from the repository root. The small examples use authored source files and need no external checkout.

| Example | What it demonstrates |
| --- | --- |
| [Graph plugins](graph-plugin/README.md) | Equivalent transitive boundary checks in Rust and TypeScript |
| [Repository rules](repository-rules/README.md) | Roles, companion files, registry imports, classification, and role dependencies |
| [Compiler members](semantic/README.md) | Optional member checks with an explicit compiler context |
| [T3 Code](t3code/README.md) | Real-repository adoption profiles and links to separate historical evidence |

The Rust example names remain `graph_plugin`, `role_inventory`, and `semantic_request`.
