Require a companion file

Check that each selected service has a corresponding analyzed layer file.

archguard.json

{
  "schemaVersion": 1,
  "include": ["src/**/*.ts"],
  "repository": {
    "roles": [
      {
        "id": "service",
        "files": ["src/services/*.ts"],
        "exclude": ["**/*.test.ts"]
      }
    ],
    "rules": [
      {
        "id": "service-companion",
        "kind": "companion",
        "role": "service",
        "replace": ["/services/", "/layers/"]
      }
    ]
  }
}

src/services/Orders.ts

export class Orders {}

Archguard reports

src/services/Orders.ts:1:1: service-companion: required analyzed companion is absent: src/layers/Orders.ts
  src/services/Orders.ts -> src/layers/Orders.ts

Fix · src/layers/Orders.ts

export const live = 1;

Exit 1 with the finding above. After the fix, exit 0.
