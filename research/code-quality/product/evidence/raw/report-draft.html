The implementation choices

The product reuses Archguard's pinned Oxc parser and binding analysis. The SDK uses Node builtins. Test runners are explicitly supplied by the caller. Compiler semantics and architecture policies remain separate.

Duplicate detection preserves calls, operators, property names and binding relationships by default. Set, counted and weighted comparisons are visible together. Mutation execution uses fresh private copies, a fresh baseline and bounded commands. Reuse is opt-in over the full declared input identity.

Findings do not impose a similarity target or a mutation score. Complete evidence exits successfully even when it contains pairs or survivors.

Tradeoffs and follow-up

Useful future work includes more repository-specific survivor classifications and a native macOS runtime trial. Cache hits alone do not prove faster analysis. Duplication and equivalent mutations still need a reviewer who understands the specification.
