Additions need another measured case

The live scout verified that Type.isErrorType() helps distinguish compiler error recovery from deliberate any; that is already used. Native batching and snapshots merit an equivalent-workload benchmark. Content mappers, source-phase imports and import-attribute matching are 7.1 candidates for explicitly trusted framework providers and import contracts.

Before broader adoption, resolve the remaining installed inventory categories individually. Before enabling cache by default, measure a cheaper invalidation approach that preserves missing-file, package-map, inherited-config and symlink correctness. Before adding more semantic facts, reproduce a merged bug that needs them.
